# MTT File Manager v0.2.9

## Choose your installer

- **Standard — `MTT-File-Manager-Setup-0.2.9.exe`:** includes online update checks and in-app download and installation. Automatic installation is optional and off by default.
- **No-update — `MTT-File-Manager-Setup-0.2.9-no-update.exe`:** excludes the entire update component. Download and install future versions manually.

**Why two editions?** Builds containing update components triggered suspected antivirus false positives during testing; reviews were requested from Google and Ikarus. The no-update installer had no VirusTotal detections in the reported test. Results may change; neither result is conclusive proof of safety or malware.

Both editions offer the same file-manager features apart from updating. Install only one; to switch, close MTT and run the other installer. Do not disable antivirus protection to install either edition.
